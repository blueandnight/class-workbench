# 班级工作台 · Class Workbench

一个在浏览器本地运行的单文件工具，用于整理班级名单、座位、课堂记录、课程安排、成绩和备忘。

## 使用

1. 下载 `index.html`，用较新的浏览器打开。
2. 初次打开是空白工作区，可按需添加数据。
3. 备份保存在本地文件中；没有账号、云同步或多人协作功能。

## 数据与隐私

应用不包含服务器端组件，也不发送网络请求。业务数据保存在当前浏览器的本地存储中，文件内容保存在 IndexedDB 中。浏览器本地数据未加密；请自行保护设备和备份。公开托管的演示版本不适合输入个人或敏感资料。

## 功能

- 名单与自定义字段
- 座位安排、床位表、值日表和课程表
- 课堂记录与历史查询
- 成绩批次、奖惩记录和备忘
- 表格导入导出、数据备份与恢复
- 本地文件清单与存储

本仓库只发布应用代码和文档，不附带真实名单、成绩、工作文件、测试报告或本地部署配置。
