班级工作台

使用提示：模板只是示例，不强制

列顺序可以打乱、用不上的列可以忽略，自己班级特有的列（走读住宿、团籍、视力…）在导入的「字段匹配」一步选择「作为自定义字段」即可存入。需要更多字段也可点「更多 → 字段设置」手动添加。

使用提示：导入模板为网格样式

讲台在前，表头「第1列、第2列…」，左侧「第1排、第2排…」，格子里填「姓名（学号）」，空白格即空座位。

使用提示：宿舍床位表

「新建宿舍」输入宿舍号后自动生成床位行；姓名从学生名单下拉选择，选「（空床位）」即留空。格子可以直接改宿舍号/床位号；保存时按学生名单校验。导出 CSV 可在 Excel 中再编辑。

使用提示：课堂点名（支持外班）

考虑到班任同时担任其他班科任的情况：默认名单是本班学生，其他班可从「花名册 ▾」粘贴姓名或导入 Excel/CSV（自动去掉序号），点名时切换名单即可。点名方式（V1.5b）：对着教室只抓异常——点名字卡片 = 记「到」（再点取消），点卡片下方「缺勤 / 请假 / 迟到」小按钮 = 标异常（再点取消）；没点的同学按「到」统计，已标异常的同学点卡片主体不会误清，需点该异常按钮取消。找人多时用「搜索姓名过滤」（V1.7）：开始点名后输入姓名关键字只显示匹配的卡片（标记不受影响，统计仍按全班口径），清空即恢复全部。保存后直接看结果（V1.8）：保存点名后面板转为结果预览——统计、缺勤/请假/迟到名单（彩色标签）、可展开的全部名单，手机上免下载直接查看；历史记录点「明细」也可就地展开同样的预览，需要存档再「导出 CSV」。保存后记录可按名单与日期筛选、导出 CSV，最多保留 500 条。只做记录与筛选，不做考勤汇总报表。

使用提示：文件保存在本浏览器，不上传网络

可存放照片、扫描件、通知、Word/PDF 等任意文件。单个文件建议不超过 20MB；请定期在「其他」页导出 JSON 备份——注意备份包含文件清单，但文件内容不会随 JSON 导出，重要文件请另行自行保存。

备份与恢复

数据保存在本浏览器的本地存储中，不是加密存储。请定期备份 JSON 文件；清除浏览器数据、更换电脑或浏览器都会导致数据丢失。

JSON 备份包含全部业务数据与文件清单，不包含文件内容（文件本体存放在本浏览器的 IndexedDB 中，恢复备份后清单里的文件需重新上传）。

导入模板下载

Excel 用户若不便导出 CSV，可直接下载 Excel 模板填写后导入；旧版浏览器不支持解析 xlsx 时，请在 Excel 中「文件 → 另存为 → CSV (逗号分隔)」后再导入。
