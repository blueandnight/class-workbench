# Class Workbench

A single-file browser app for organizing class lists, seating, schedules, records, and notes.

## Use

1. Download `index.html` and open it in a modern browser.
2. The app starts with a blank workspace.
3. Backups are saved as local files. There is no account, cloud sync, or multi-user feature.

## Data and privacy

The app has no server component and makes no network requests. Business data stays in the current browser's local storage; file contents use IndexedDB. Local browser data is not encrypted. Protect the device and backup files. Do not enter personal or sensitive information into a publicly hosted demo.

## Features

- Lists and custom fields
- Seating, beds, duty tables, and schedules
- Records and history
- Score batches, incident records, and notes
- Spreadsheet import/export and backup/restore
- Local file catalog and storage

This repository publishes only the app source and documentation. It does not include real lists, scores, workplace files, test reports, or local deployment configuration.
